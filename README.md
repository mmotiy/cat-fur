# cat-fur · 2D 猫咪贴纸毛发渲染（WebGL2 Shell-Fur）

让一张 2D 卡通猫咪贴纸图"长出毛发"的单文件网页 demo。

## 运行

双击 `index.html` 即可（三张贴图已 base64 内嵌），或：

```bash
python -m http.server 8734
# 打开 http://127.0.0.1:8734/index.html
```

## 交互

- 鼠标划过猫咪：拨动毛发（轮廓毛 + 身体毛丝都会被拨开）
- 右侧面板：毛长 / 毛簇大小 / 层数 / 重力 / 风力 / 鼠标拨毛 / 身体毛发 / 流向 / 生长进度
- 「风格」按钮：贴纸毛 ↔ 绒毛 两套预设
- 拖拽任意纯色背景 / 透明底贴图到页面可换图（无配套法线/高度贴图时自动中性回退）

## 技术

单 pass WebGL2 壳层毛发（shell fur）+ 三贴图工作流：

| 贴图 | 用途 |
|---|---|
| baseMap（cats.jpg） | 毛色来源（毛根位置采样）；同时用于提取遮罩与符号距离场 |
| 法线贴图（nrm.jpg） | 毛流方向：切向空间 `n.xy = -∇height`，顺坡梳理（背脊分缝、胡须外撇） |
| 高度贴图（hgt.jpg） | 毛长调制（高处/鬃毛更长）+ 毛根 AO（低洼压暗） |

- CPU 端：Felzenszwalb EDT 计算符号距离场（SDF），R16F 纹理上传
- GPU 端：单 pass 全屏 fragment shader，K 层虚拟壳 + 弯折回采样；
  远离轮廓的像素一次采样即剪枝
- 身体内部毛丝：沿毛流排布的有根/有梢/有长度的细毛，根固定、
  梢部随鼠标推力与风弯曲（与轮廓毛共用扰动场）

## 已知限制

- 换图仅支持纯色背景或透明底（复杂照片背景抠图不保证）
- 身体毛丝为着色器程序化生成，密度与底图美术风格相关
